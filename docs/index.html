Why Hideout

Privacy that never leaves the device

No server, no API key, no per-request bill. The text you are protecting is never sent anywhere to be checked.

Made for Indian apps

Indian phone formats, Aadhaar (also masked), PAN, UPI IDs, IFSC, voter ID, driving licence and vehicle numbers, addresses with PIN codes and Indian names, in English, Hinglish, Hindi and other Indian languages.

One line in your Gradle file, from Maven Central. Works in commonMain for Android, iOS, macOS, JVM desktop, JavaScript and WebAssembly. No API key, no account.

Usage

One call per message

Load once and reuse the instance. find() and hide() are thread-safe.

Kotlin
val hideout = Hideout()

hideout.hide("Account no 50100234567812, IFSC HDFC0001234")
// "Account no [BANK_ACCOUNT], IFSC [IFSC]"

hideout.find("Call Rahul on 98765 43210")
// [Pii(NAME, 5, 10, "Rahul", 0.998), Pii(PHONE, 14, 25, "98765 43210", 1.0)]

hideout.hide("OTP is 482913", replacement = { "*".repeat(it.text.length) })
// "OTP is ******"

hideout.close()
Java
try (Hideout hideout = new Hideout()) {
    String safe = hideout.hide(
        "Call me on 98765 43210, my UPI is raju@okaxis");
}

FAQ

Questions

What is Hideout?

A Kotlin Multiplatform library (Android, iOS, macOS, JVM desktop, JavaScript, WebAssembly) that finds personal information in text (phone numbers, UPI IDs, Aadhaar, PAN, card and bank numbers, emails, names, addresses, passwords and OTPs and more) and hides it.

Which languages does it support?

English, Hinglish and romanised Tamil / Telugu, Hindi, Marathi, Bengali, Tamil, Telugu, Kannada, Malayalam, Gujarati, Punjabi and Urdu, plus Spanish, French, German, Italian, Dutch and Portuguese. Numbers, emails and IDs are found in any language. Chinese, Japanese and Thai are not supported.

Will it hide ordinary numbers?

Mostly not: prices, times, order IDs, UPI transaction references, PNRs, room numbers and cities stay visible. On fresh test messages with no personal info, 95% were left untouched. Raise threshold to hide less, lower it to hide more.

Is it a replacement for regex rules?

It reads context, so it knows "my OTP is 482913" from "I paid 482913", finds names, and handles numbers typed with spaces, dashes or +91. If you also have strict formats of your own, you can run your rules next to it.

How long can the text be?

Any length. Long text is cut into overlapping windows, so every word is judged with context on both sides.

How fast is it on a phone?

It is the same size and speed class as Comma: a few milliseconds per chat message on a laptop JVM, and on an Android emulator on the same day it ran as fast as Comma. Load it once, off the main thread, and reuse it.

Does it run on device?

Yes. Inference runs entirely on the device in plain Kotlin. It makes no server calls, needs no network permission and sends no telemetry.

Is the Kotlin port exact?

Units, token ids, every label and the hidden text match the reference implementation on all 197 test vectors, both on the JVM and on an Android device.

How much does Hideout cost?

Nothing for products with up to 10,000 monthly active devices per platform, including commercial apps. There is no API key or account, and no limit on how often it runs. Above that, a commercial license is needed; see Pricing.
